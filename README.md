# bobolog — PWA บันทึกผลตรวจเลือดและสุขภาพย้อนหลัง

(เดิมชื่อ BloodLog — ชื่อฐานข้อมูลในเครื่อง ชื่อแคช และช่อง `app` ในไฟล์สำรองยังใช้ `bloodlog` เพื่อให้ข้อมูลเดิมใช้ต่อได้)

Vanilla JS ไม่มี build step ข้อมูลเก็บใน IndexedDB ของเครื่องเท่านั้น OCR ทำในเครื่อง (Tesseract.js รวมอยู่ใน `vendor/` ไม่เรียก CDN)

## ใช้งาน / deploy
- ทดสอบในเครื่อง: `python3 -m http.server 8080` แล้วเปิด http://localhost:8080
- GitHub Pages: push ทั้งโฟลเดอร์ขึ้น repo → Settings → Pages → Deploy from branch (root) → เปิด URL บนมือถือ → "Add to Home Screen"
- PWA ต้องเสิร์ฟผ่าน HTTPS (หรือ localhost) เท่านั้น

## โครงสร้าง
- `index.html` หน้าแอป + CSS
- `app.js` UI, IndexedDB, กราฟ SVG, ส่งออก PDF (ผ่าน print), สำรอง/กู้คืน JSON
- `parser.js` รายการตรวจมาตรฐาน + ช่วงอ้างอิง + ตัวแปลงข้อความ OCR
- `sec.js` เข้ารหัส / PIN / ลายนิ้วมือ, `ocrtools.js` ครอบตัดรูปและอ่าน PDF
- `version.js` เลขเวอร์ชัน (แก้ที่นี่ที่เดียวทุกครั้งที่อัปเดตไฟล์ — แสดงท้ายหน้าตั้งค่า และเป็นชื่อแคชของ service worker)
- `sw.js` service worker
- `vendor/tesseract/` Tesseract.js 7 + โมเดลภาษาอังกฤษและไทย, `vendor/pdfjs/` pdf.js 4.10 (legacy build)

## ข้อมูลที่เก็บ
- โปรไฟล์: ชื่อ เพศ วันเกิด (คำนวณอายุ) ส่วนสูง
- ผลเลือดจากแล็บ (`kind: 'lab'`) — OCR หรือกรอกเอง
- วัดร่างกาย (`kind: 'body'`) — ความดัน ชีพจร น้ำตาลปลายนิ้ว น้ำหนัก BMI (คำนวณจากส่วนสูง) ไขมัน รอบอก/เอว/สะโพก
- เกณฑ์แยกตามเพศ (`bySex`) สำหรับ Hb, Hct, RBC, Creatinine, Uric acid, HDL, รอบเอว

## หน้าภาพรวม
- แต่ละค่าเป็นแถวเดียว: ชื่อ ค่าล่าสุด สถานะ — แตะเพื่อดูกราฟและประวัติย้อนหลัง
- เรียงตามความสำคัญ: สรุปหนึ่งบรรทัด → ค่าที่นอกเกณฑ์ → ปักหมุด → กลุ่มที่เหลือ (พับไว้ เปิดค้างได้)
- ปุ่ม "＋ บันทึก" ปุ่มเดียว เปิด 4 ตัวเลือก: ความดัน / น้ำหนัก / น้ำตาล / ผลเลือด; ทางลัดกดค้างที่ไอคอนแอป (`?quick=bp|weight|sugar`, Android)
- ความดันแสดงเป็นคู่ ตัวบน/ตัวล่าง; การวัดห่างกันไม่เกิน 10 นาทีในวันเดียวกันถูกเฉลี่ยเป็นรอบเดียว; มีค่าเฉลี่ย 7/30 วัน
- เปิดครั้งแรก: แนะนำ 3 ขั้น (โปรไฟล์ → ติดตั้ง → PIN) ข้ามได้ และกู้คืนจากไฟล์สำรองได้จากหน้านี้
- ตั้งค่าเป็นเมนู 5 หัวข้อ: โปรไฟล์ / การแสดงผล / ความปลอดภัย / สำรองข้อมูล / รายการตรวจ (มีโหมด "จัดเรียง" สำหรับปักหมุด ซ่อน เลื่อนลำดับ)

## ติดตั้งเป็นแอป
- Android: ปุ่มติดตั้งของเบราว์เซอร์; iPhone: Safari → แชร์ → "เพิ่มไปยังหน้าจอโฮม"
- เปิดจาก LINE / Facebook / Instagram ติดตั้งไม่ได้ — แอปจะบอกให้เปิดใน Safari หรือ Chrome ก่อน
- iPhone: แอปที่ติดตั้งแล้วมีที่เก็บข้อมูลแยกจาก Safari ข้อมูลที่กรอกไว้ก่อนติดตั้งจะไม่ตามมา — ให้สำรองข้อมูลก่อน แล้วกู้คืนในแอปที่ติดตั้ง (แอปเตือนเองเมื่อมีข้อมูลอยู่)

## ความปลอดภัย (`sec.js`)
- ตั้ง PIN (6–12 หลัก) → ข้อมูลใน IndexedDB ถูกเข้ารหัสด้วย AES-256-GCM; กุญแจข้อมูลถูกห่อด้วยกุญแจจาก PBKDF2-SHA256 600,000 รอบ
- ลายนิ้วมือ / Face ID ใช้ WebAuthn PRF: กุญแจได้จากชิปความปลอดภัยของเครื่องเมื่อสแกนผ่าน (ต้องเป็นเบราว์เซอร์ที่รองรับ PRF)
- ล็อกอัตโนมัติเมื่อออกจากแอปเกิน 2 นาที; ลืม PIN = ต้องลบข้อมูลแล้วกู้จากไฟล์สำรอง
- ไฟล์สำรองเข้ารหัสด้วยรหัสผ่านแยกต่างหาก (≥ 8 ตัวอักษร) ที่ตั้งตอนส่งออก
- PIN ตัวเลขสั้นกันคนหยิบเครื่องไปเปิดดู ไม่ได้กันการเดาแบบออฟไลน์ถ้าข้อมูลดิบของเบราว์เซอร์ถูกคัดลอกออกไป

## การอ่านใบแล็บ (`ocrtools.js`)
- รูปถ่าย: แอปหาทิศของตัวหนังสือ (ลองอ่านเร็วทีละทิศ) ปรับเอียง (±10°) และครอบส่วนที่มีตัวหนังสือให้อัตโนมัติ แล้วลดเงา — ปรับเองได้ทุกอย่างในหน้าครอบตัด
- รูปถ่ายเฉียง: หามุมกระดาษ 4 จุด (เมื่อสีกระดาษต่างจากพื้นหลังและกระดาษอยู่ในรูปครบ) แล้วดึงให้เป็นสี่เหลี่ยมด้วย homography; ลากมุมทั้ง 4 เองได้อิสระ
- เลือกได้ทั้งถ่ายใหม่ และเลือกรูป/PDF ที่มีในเครื่อง
- หลังอ่าน: หน้าตรวจค่า ติ๊กเลือก/ไม่เลือก (มีเลือกทั้งหมด/ไม่เลือกเลย) และแก้ตัวเลขได้ก่อนนำเข้าฟอร์ม
- PDF: อ่านชั้นข้อความตรง ๆ ด้วย pdf.js (รองรับไฟล์ตั้งรหัสผ่าน); PDF สแกนจะถูกแปลงเป็นรูปแล้วเข้า OCR
- PDF ที่เป็นตารางเทียบหลายปี (หัวตารางเป็นปี เช่น 2026 | 2025 | 2024): ใช้ตำแหน่งคอลัมน์แยกค่าของแต่ละปีและค่าอ้างอิง นำเข้าเฉพาะคอลัมน์ผลปัจจุบัน
- ค่าร่างกายในใบเดียวกัน (น้ำหนัก BMI ความดัน ชีพจร) ถูกบันทึกเป็นรายการ "วัดร่างกาย" แยกต่างหาก
- ตัวเลขที่เป็นค่าอ้างอิง (ช่วง "0.38 - 5.33" หรือมี < > นำหน้า) ไม่ถูกนับเป็นผลตรวจ
- ค่าที่ห่างจากเกณฑ์เกิน 5 เท่าจะไม่ถูกติ๊กให้และมีขอบแดง (มักเป็นจุดทศนิยมหาย)

## อื่น ๆ
- เตือนเมื่อไม่ได้สำรองเกิน 30 วัน, ปุ่ม "เลิกทำ" 8 วินาทีหลังลบ, ตารางสรุปในแอป, โหมดผู้สูงอายุ
- ค่าคำนวณ: eGFR (CKD-EPI 2021), Non-HDL, LDL (Friedewald), รอบเอว/ส่วนสูง, รอบเอว/สะโพก

## ข้อจำกัด
- OCR อ่านทั้งอังกฤษและไทย (Tesseract `eng+tha`): รู้จักชื่อรายการภาษาไทย วันที่แบบไทย (15 มี.ค. 2569) และเลขไทย — ต้องตรวจทานค่าก่อนบันทึกเสมอ
- การหาทิศของรูปใช้อังกฤษอย่างเดียว (ดูตัวเลขและหน่วย) เพราะโมเดลไทยให้ความมั่นใจสูงแม้รูปตะแคง; ใบที่เป็นไทยล้วนต้องลองครบ 4 ทิศ จึงช้ากว่า
- ช่วงค่าอ้างอิงเป็นค่าทั่วไปของผู้ใหญ่ แก้ได้ในหน้าตั้งค่า
